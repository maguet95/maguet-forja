# Maguet · La forja

El taller que arma el instalador de cada comunidad de Maguet con su marca (su logo, su imagen de bienvenida y su
nombre) alrededor del **mismo programa** que reciben todos.

- Solo arranca cuando Maguet aprueba una comunidad.
- El código que corre no vive aquí: viene en el kit de cada versión del launcher, y su huella se comprueba antes de
  ejecutar nada.
- El programa de dentro se comprueba byte a byte (huella del asar) contra el publicado: si no cuadra, no se entrega.
- Los secretos solo existen como secretos de este repositorio.
